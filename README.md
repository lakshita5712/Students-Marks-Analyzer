Student Marks Analyzer

A simple Python project to analyze student marks using NumPy and Pandas.
This project helps in understanding data analysis basics like average marks, highest score, lowest score, pass/fail status, and subject-wise performance.

Features

Calculate:
Average marks,
Highest marks,
Lowest marks,
Total marks,
Percentage,
Ranking System,
Find topper student,
Pass/Fail analysis,
Subject-wise statistics,
Data Visualization using Pandas

Technologies Used

Python,
NumPy,
Pandas
